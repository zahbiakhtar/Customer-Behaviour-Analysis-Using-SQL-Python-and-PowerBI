## 📌 Project Overview
This project focuses on analyzing customer purchasing behavior to generate business insights related to revenue, customer segmentation, product performance, discounts, subscriptions, shipping preferences, and payment methods.

The analysis was performed using SQL for querying, Python for preprocessing, and Power BI for interactive dashboard visualization.

---

## 🚀 Objectives
- Analyze customer spending patterns
- Identify top & bottom performing products
- Understand revenue contribution by gender and age groups
- Evaluate discount and subscription effectiveness
- Perform customer segmentation
- Discover trends across categories, locations, seasons, and payment methods

## 📈 Key Insights
- Electronics category generated the highest revenue
- Male customers contributed the highest spending share
- Debit Card was the most preferred payment method
- Discounts significantly influenced purchase behavior
- Some high-revenue products received lower customer ratings
