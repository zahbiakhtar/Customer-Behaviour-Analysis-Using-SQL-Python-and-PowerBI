Customer Behaviour Analysis using SQL, Python & Power BI
Project Overview

This project analyzes customer purchasing behavior to uncover insights related to revenue, customer preferences, discounts, subscriptions, ratings, demographics, shipping methods, and payment trends. The project combines SQL for data analysis, Python for preprocessing, and Power BI for interactive dashboard visualization.

Objectives
Analyze customer spending behavior
Identify high-performing and low-performing products
Understand revenue contribution by gender and age groups
Evaluate discount and subscription effectiveness
Segment customers based on purchasing patterns
Discover revenue trends by location, category, season, and payment method
Tools & Technologies Used
SQL (MySQL Workbench) – Data querying and analysis
Python – Data cleaning and preprocessing
Power BI – Interactive dashboard creation and visualization
GitHub – Project version control and portfolio showcase
Key Features
Customer segmentation analysis
